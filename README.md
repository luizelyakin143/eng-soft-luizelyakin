Este repositório foi criado para a atividade prática de controle de versões, utilizando o GitHub para registrar alterações e organizar o desenvolvimento de um projeto.

## Objetivo do repositório

O objetivo deste repositório é praticar o controle de versões por meio do GitHub. A atividade envolve a criação de commits, o uso de branches e a revisão de alterações através de um Pull Request antes da incorporação à branch principal.
